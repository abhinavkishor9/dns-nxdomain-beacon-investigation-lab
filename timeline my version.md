### Significance

This event provided the strongest process-attribution evidence from the investigation.

The failed DNS request was associated with:

```text
PowerShell
PID 2064
User: DESKTOP-9MMM37V\Dell
```

The query status was:

```text
9003
```

which is consistent with the queried DNS name not existing.
